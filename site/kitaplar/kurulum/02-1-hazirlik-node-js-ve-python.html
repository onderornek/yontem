1. Hazırlık: Node.js ve Python

Node.js 22 veya üstü gerekir; Python yalnızca yorumlayıcıyı kullanacaksanız gerekir. Önce bunların zaten kurulu olup olmadığına bakabilirsiniz:

Terminal
node --version     # v18.0.0 veya üstü olmalı
npm --version
python3 --version  # Windows'ta: py --version (3.11 veya üstü)

Windows

  • Node.js: nodejs.org adresinden LTS sürümünü indirip kurabilir ya da PowerShell’de winget install OpenJS.NodeJS.LTS yazabilirsiniz.
  • Python: python.org adresinden kurabilirsiniz; kurulumda Add python.exe to PATH kutusunu işaretlemeniz gerekir.
  • Kurulumdan sonra terminali kapatıp yeniden açmanız gerekir; yoksa yeni komutlar bulunamaz.

macOS

  • Homebrew varsa brew install node ve brew install python komutları yeterlidir.
  • Yoksa iki programı da nodejs.org ve python.org kurulum paketleriyle kurabilirsiniz.

Linux (Ubuntu, Debian)

Terminal
sudo apt update
sudo apt install nodejs npm python3
node --version

Dağıtımınızın paket deposundaki Node.js 22’den eskiyse (örneğin Ubuntu 24.04), Node.js’i nvm ile kurabilirsiniz: nvm install --lts.
