Kurulum kılavuzu · Yöntem 0.6.0

Yöntem'i bilgisayarınıza kurabilirsiniz.

Çoğu kullanıcı için Node.js ve tek bir komut yeterlidir. Python yorumlayıcısı ve ESP32 desteği isteğe bağlıdır. Hiçbir şey kurmadan denemek isterseniz oyun alanını kullanabilirsiniz.

Hangi kurulum size uygun?

Program yazıp çalıştırmak için yalnızca JavaScript derleyicisi yeterlidir. Diğerleri belirli işler için eklenir. Kaynak dosyaların uzantısı .y'dir.

1. Node.js ve Python

Önce bunların kurulu olup olmadığına bakabilirsiniz. node --version v18 ya da üstünü göstermelidir. Python yalnızca yorumlayıcıyı kullanacaksanız gerekir.

  • Node.js: nodejs.org adresinden LTS sürümünü kurabilir ya da PowerShell'de winget install OpenJS.NodeJS.LTS yazabilirsiniz.
  • Python: python.org adresinden kurabilirsiniz; kurulumda Add python.exe to PATH kutusunu işaretlemeniz gerekir.
  • Kurulumdan sonra terminali kapatıp yeniden açmanız gerekir. Komutlarda python3 yerine py yazabilirsiniz.
  • Homebrew kuruluysa: brew install node ve brew install python.
  • Değilse nodejs.org ve python.org kurulum paketlerini kullanabilirsiniz.
 
sudo apt update
sudo apt install nodejs npm python3
node --version

Dağıtımınızın Node.js sürümü 18'den eskiyse (örneğin Ubuntu 22.04) nvm ile kurabilirsiniz: nvm install --lts.

2. JavaScript derleyicisi

Yöntem, npm paket deposunda yontem adıyla yayımlanır. Kurulum tek komuttur; ayrıca bir şey indirmeniz ya da derlemeniz gerekmez.

  1. Önce derleyiciyi kurabilirsiniz: 
    npm install -g yontem   # derleyici, kitaplık ve "yontem" komutu
  2. Ardından ilk programınızı yazıp çalıştırabilirsiniz. merhaba.y: 
    program Merhaba
başla
  yaz('Merhaba, Yöntem!', 1)
bitir.
    yontem merhaba.y                 # derler ve çalıştırır
yontem derle merhaba.y -o m.js   # yalnızca JavaScript üretir; node m.js
yontem --surum                   # Yöntem 0.6.0 (JavaScript)
İpucu: Genel kurulum istemezseniz proje klasöründe npm install yontem yazıp npx yontem program.y ile çalıştırabilirsiniz. Örnek programlar, testler ve Python yorumlayıcısı için depoyu alabilirsiniz: git clone https://github.com/onderornek/yontem.git. Birimler programın klasöründe, onun kutuphane alt klasöründe ve Yöntem'in kendi kitaplığında aranır.

3. Python yorumlayıcısı

Yorumlayıcı Yöntem'in deposuyla gelir ve ayrı bir kurulum gerektirmez: depo klasöründeki yontem.py dosyasını çalıştırmanız yeterlidir. Aynı çıktıyı verir ama daha yavaştır; asıl gücü etkileşimli kabuktur.

python3 yontem.py merhaba.y   # programı çalıştırır (Windows: py yontem.py)
python3 yontem.py             # etkileşimli kabuk; çıkmak için: çıkış

4. ESP32 ve gömülü arka uç

Gömülü arka uç yontem komutuyla gelir. Masaüstü benzetimi için bir C++17 derleyicisi, karta yüklemek için bir yükleme aracı gerekir.

Linuxsudo apt install g++
macOSxcode-select --install
WindowsMSYS2 ile MinGW g++ (henüz sınanmadı)
yontem gomulu led.y --calistir   # C++'a derler, bilgisayarda çalıştırır
yontem gomulu led.y              # ESP32 projesi üretir: led/ klasörü

Karta yükleme. Üretilen klasörü Arduino IDE'de açabilir (kart: "ESP32 Dev Module", Espressif'in esp32 çekirdeği 3.x önerilir) ya da klasörde pio run -t upload komutunu çalıştırabilirsiniz. arduino-cli komutları klasördeki BENIOKU.txt dosyasında yer alır. Seri hız 115200 baud'dur.

5. Doğrulama ve sorunlar

Kurulumu doğrulamak için yontem --surum komutunun sürüm numarasını yazması yeterlidir; güncellemek için npm install -g yontem@latest yazabilirsiniz. Yöntem'i kaynaktan kurduysanız kendi testlerini de çalıştırabilirsiniz; hepsi "geçti" demelidir. Kaynaktan kurulumda güncellemeden sonra yontem/js içinde npm install ve npm run build komutlarını yeniden çalıştırmanız gerekir.

node js/betikler/test.js          # JavaScript derleyicisi
python3 testler/calistir.py       # Python yorumlayıcısı
node js/betikler/gomulu_test.js   # gömülü arka uç
