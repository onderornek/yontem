Özet

Aynı algoritmalar dört dilde yazıldı ve aynı bilgisayarda ölçüldü. Açılış süresi çıkarıldığında, sekiz hesaplama testinin geometrik ortalamasına göre Yöntem'in ürettiği C++ kodu elle yazılmış C++'tan 1,9 kat, JavaScript'e derlenen Yöntem 29 kat yavaş çalıştı. Python yorumlayıcısı öğrenme ve başvuru amaçlıdır; hız için tasarlanmamıştır.

Ölçümün kapsamı ve sınırları

  • Ölçüm 2026-11-09 tarihinde, Yöntem 0.5.0 ile tek bir Linux bilgisayarında (x86-64) yapıldı. Başka donanımda oranlar değişebilir.
  • "Yöntem → C++" satırı, gömülü arka ucun ürettiği C++ kodunun bilgisayarda g++ -O2 ile derlenmiş hâlidir. ESP32 kartında ölçüm yapılmadı; bu sayılar kart üzerindeki hızı göstermez.
  • Dokuz testten biri (bos) yalnızca açılış süresini ölçer ve oranlardan çıkarılır; oranlar kalan sekiz testten hesaplanır.
  • Her test ısınmadan sonra 7 kez çalıştırıldı ve ortanca süre alındı. Çıktısı beklenenle birebir aynı olmayan ölçüm geçersiz sayılır.
  • Testler küçük hesaplama çekirdekleridir; dosya, ağ ya da arayüz ağırlıklı programlar için bir şey söylemez.

Ölçümü kendiniz yinelemek

Test programları, beklenen çıktılar ve ölçüm betiği Yöntem deposunun benchmark/ klasöründedir. Node.js, Python 3 ve g++ (ya da clang++) kurulu bir bilgisayarda:

cd js && npm install && npm run build && cd .. python3 benchmark/calistir.py

Sonuçlar benchmark/sonuclar/ klasörüne yazılır: rapor.md (bu sayfadaki tablolar), rapor.json (ham ölçümler) ve rapor.svg (grafik). Kendi ölçümünüzde farklı bir sonuç görürseniz topluluk sayfasındaki yoldan bildirebilirsiniz.
